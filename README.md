# Negar Web Application (نرم‌افزار جامع نگار تحت وب)

یک سیستم کامل، منسجم و مدرن بر پایه **#ASP.NET Core 8 C** و دیتابیس **PostgreSQL** برای مدیریت مال، حسابداری، انبارداری، خرید و فروش، و دسترسی‌های کاربران با فرانت‌اند راست‌چین و مدرن وب و پشتیبانی از برنامه‌های موبایل (PWA/API).

## 🚀 ویژگی‌های کلیدی
- **بک‌اند RESTful C# API** با توکن JWT جهت اتصال برنامه‌های فرانت‌اند و موبایل (React Native, Flutter, PWA)
- **پایگاه داده PostgreSQL** با EF Core و اسکریپت آماده `Database/postgres_schema.sql`
- **کدگذاری حساب‌ها (درختی)**: گروه، کل، معین و تفصیلی همراه با حساب‌های شناور
- **ثبت و صدور اسناد حسابداری (سند ۱ و ۲)** همراه با کنترل توازن و تاییدیه اسناد
- **انبارداری و کالاها**: تعریف گروه کالا، کالاها، انبارها و موجودی انبار همراه با میانگین بهای تمام شده
- **فاکتورهای خرید و فروش**: ثبت فاکتورها، بروزرسانی انبار و صدور سند اتوماتیک
- **کاربران و سطوح دسترسی**: ماتریس کامل دسترسی‌ها (مشاهده، ایجاد، ویرایش، حذف، چاپ، خروجی)
- **مدیریت شرکت‌ها و سال‌های مالی**
- **فرانت‌اند مدرن، واکنش‌گرا و قابل نصب (PWA)** با سه تم رنگی (آبی، تیره، روشن)

## 📁 ساختار پروژه
- `src/Negar.Domain`: مدل‌های انتیتی، دامنه و انوم‌ها
- `src/Negar.Infrastructure`: اتصال به دیتابیس EF Core PostgreSQL، سرویس‌های امنیت و JWT
- `src/Negar.Application`: سرویس‌های مدیریت حسابداری، انبار و کاربران
- `src/Negar.Api`: اندپوینت‌های Web API و پیکربندی Swagger
- `src/Negar.Web`: فرانت‌اند وبی کامل (HTML5/CSS3/JS/PWA)
- `Database/postgres_schema.sql`: اسکریپت کامل DDL ساخت جداول و داده‌های اولیه در PostgreSQL

## 🛠 راه‌اندازی دیتابیس PostgreSQL
1. دیتابیس `negar_db` را در PostgreSQL ایجاد کنید.
2. اسکریپت `Database/postgres_schema.sql` را اجرا نمایید.
3. در صورت نیاز، رشته اتصال را در `src/Negar.Api/appsettings.json` بروزرسانی کنید.
